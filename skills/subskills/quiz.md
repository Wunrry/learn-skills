# Graded Checks

Use this subskill for calibration and for checking whether a dependency node landed.

## Find the edge

Probe every prerequisite strand the lesson will use. For each strand, establish a floor the learner can handle and a ceiling where the model breaks. Increase difficulty sharply after a correct answer; narrow around a miss to distinguish a slip from a gap or misconception. One answer never maps the whole strand.

## Construct options

For a multiple-choice check:

1. Write the correct claim as a bare statement.
2. Mutate it into each distractor using a real, tempting misconception.
3. Keep the options parallel in length, grain size, register, and formatting.
4. Put all reasoning in the post-answer explanation, never inside only the correct option.

The learner should not be able to identify the answer from style, length, or emphasis alone.

## Give feedback

Let the learner commit before revealing the answer. State whether the response is correct, name the relevant dependency, and explain why the tempting alternatives fail. A miss means repair and re-check before dependent material is built. A correct answer establishes a floor; raise the difficulty when the goal requires it.
