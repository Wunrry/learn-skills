# Markdown Output and Logs

Use plain Markdown as the portable record format.

Preserve the session's order and meaning. Keep headings, lists, fenced code, LaTeX, links, image paths, and the learner's answers intact. Add timestamps only when the host supplies a reliable clock or the learner asks for them.

For an image, use a relative Markdown link and a useful alt description. For an unrendered visual, keep the source in a fenced block and label its verification state. Do not assume a particular vault, note application, wikilink syntax, or automatic synchronization.

When updating an existing log, append or edit exact sections rather than rewriting unrelated history. If persistence is unavailable, return the Markdown explicitly and say that the host must save it.
