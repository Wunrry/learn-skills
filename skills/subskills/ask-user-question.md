# Open Question Capability

Use an open question when the learner must choose a goal, priority, example, pace, or direction and there is no objectively correct answer.

Ask only what will change the next teaching decision. Offer a small set of concrete choices when that reduces effort, but allow a free-form response. Wait for the response before committing to a materially different scope.

Do not use an open question for a fact, derivation, prediction, or diagnosis with a known answer. Those belong to a graded check.
